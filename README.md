# JOY / WITHIN

Полноэкранная интерактивная визуализация эмоции радости.

- Мужской силуэт без головы: только широкие плечи и торс.
- Сердце — WebGL point cloud: до 220 000 частиц на desktop, адаптивно меньше на мобильных устройствах.
- Частицы пульсируют, мерцают и реагируют на мышь/палец: отталкиваются и закручиваются вокруг точки касания.
- `joy(t, interaction)` реально управляет пульсом, яркостью и размером частиц.
- Один файл `index.html`, без библиотек и сборки.

## Запуск

Откройте `index.html` в современном браузере. Для публикации на GitHub Pages достаточно положить `index.html` в корень репозитория и включить Pages.
